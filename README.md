# IB Computer Science 2027

A free, single-page study site for the **new IB Diploma Computer Science course** (first assessment May 2027), covering SL and HL. Code examples use Python; the IB sets Paper 2 in both Python and Java versions, and your school chooses one.

## What's inside

- **Theme A (Concepts):** A1 Computer fundamentals, A2 Networks, A3 Databases, A4 Machine learning
- **Theme B (Computational thinking):** B1 Computational thinking, B2 Programming (including stacks and queues), B3 Object-oriented programming, B4 Abstract data types (HL only: linked lists, binary search trees, sets, hash tables)
- **Internal Assessment:** the computational solution — criteria, schedule, video and checklist
- **Paper 1 case study:** a step-by-step method and glossary template
- **Exam technique:** command terms, answer structures and common errors
- **73 practice questions** with mark-scheme notes (24 are HL only)

## Features

- **SL / HL switch** hides HL-only questions and the B4 section
- **Progress tracking** — mark each section done and self-mark every practice question ("Got it" / "Review later"); saved in your browser only
- **Review filters** to show just the questions you flagged or haven't tried
- **Dark mode**, keyboard-friendly navigation, print-friendly layout, mobile layout
- No build step, no dependencies, no tracking

## Run it

Open `index.html` in a browser. To publish, enable **GitHub Pages** (the included workflow in `.github/workflows/static.yml` deploys the repo on every push to `main`).

`index-1.html` is a small redirect kept so older links still work.
